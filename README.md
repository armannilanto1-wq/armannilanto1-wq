## 07 / THE ENGINEER'S CHALLENGE

### THE FORTIS SIGNAL TEST

*Three scenarios. Three engineering decisions.*

</div>

<details>
<summary><strong>LEVEL 01 — THE SYSTEM FAILURE</strong> | A beautiful application has a broken checkout. What comes first?</summary>

**Answer / Investigate the complete transaction flow.**

Reproduce the issue, inspect frontend validation, API responses, backend logic, database operations, and error handling.

**Principle:** Functionality before decoration.

</details>

<details>
<summary><strong>LEVEL 02 — THE AI PROBLEM</strong> | An AI assistant produces inconsistent results. How do you improve it?</summary>

**Answer / Build an evaluation and validation process.**

Define expected outputs, improve context, test representative inputs, handle edge cases, and establish suitable safeguards.

**Principle:** Intelligence needs engineering discipline.

</details>

<details>
<summary><strong>LEVEL 03 — THE AUTOMATION TEST</strong> | A team repeats the same manual task every day. What's your approach?</summary>

**Answer / Map the workflow and identify reliable automation opportunities.**

Connect suitable APIs, services, triggers, and validation steps. Tools such as n8n can help orchestrate workflows.

**Principle:** Automate with purpose, not complexity.

</details>
